# СК проекта: UTM и МСК

Модуль QGIS: для центра карты показывает зону UTM и местные системы координат
(МСК) субъекта РФ, выбранную назначает проекту.

## Как пользоваться

Кнопка «СК» на панели «Альтан-Эко» или
«Модули → Альтан-Эко → СК проекта по центру карты (UTM, МСК)…».

В окне:
- первая строка — WGS 84 / UTM зоны, куда попадает центр карты: EPSG:326NN на
  севере, EPSG:327NN на юге, с особыми зонами у Норвегии и Шпицбергена;
- ниже — МСК субъекта РФ, в котором центр карты. Субъект определяется через
  OpenStreetMap (нужен интернет). Подходящая зона — с ближайшим осевым
  меридианом — выделена жирным. Полное название и осевой меридиан видны, если
  навести курсор на строку;
- если МСК для места нет (за пределами России или субъекта нет в наборе) —
  ближайшие зоны СК-63: своя и соседние, по осевому меридиану. Они берутся из
  базы EPSG (Pulkovo 1942 / CS63 zone …), например «СК-63 район X зона 4
  (EPSG:7828)» для Херсонской области.

Выберите строку и нажмите «Назначить проекту» (или дважды щёлкните по ней).
Карта остаётся на том же месте, слои и их данные не меняются. «Определить
заново» — после того как вы сдвинули карту.

## Что нужно знать

- Севернее 84° и южнее 80° ю. ш. зон UTM нет — строки UTM не будет.
- Без интернета показывается только UTM: без ответа сервиса неизвестно, есть ли
  для места МСК, поэтому и зоны СК-63 не показываются. Ответа модуль ждёт
  10 секунд, после чего так и пишет, что связи нет.
- Встроено 257 МСК по 81 субъекту. Нет МСК для Тывы, Хакасии, Еврейской АО
  и Севастополя. МСК-90 Крыма окно само не предложит: OpenStreetMap относит
  Крым к Украине, и там показываются зоны СК-63 района X (4 и 5) — с теми же
  параметрами, что у МСК-90. Параметры взяты из рабочего набора и официально не
  проверялись.
- При назначении МСК добавляется в «Пользовательские СК» QGIS под своим
  названием (если такой ещё нет), чтобы название было видно в проекте.
- В сервис Nominatim (OpenStreetMap) уходят только координаты центра карты,
  округлённые до 0,001° (около 100 м).

Требуется QGIS 3.40 или новее. Проверен в QGIS 3.40.5, 3.44 (Qt5) и 4.2.3 (Qt6) на macOS:
прогон тестов и запуск в настоящем QGIS. В Windows и Linux не проверялся.

## Разработка

- `tests/run_tests.sh` — проверки на Python из QGIS без окна.
- `./build_zip.sh` — архив `dist/project_utm_crs-<версия>.zip`.
- `tools/build_msk_json.py <qgis.db>` — пересобрать `project_utm_crs/msk.json`
  из пользовательских СК профиля QGIS.
