# UTM СК проекта

Модуль QGIS: одна кнопка ставит проекту систему координат UTM той зоны,
куда попадает центр карты.

## Как пользоваться

Кнопка с глобусом на панели «Альтан-Эко» или
«Модули → Альтан-Эко → СК проекта — UTM по центру карты».

- Проекту назначается WGS 84 / UTM zone NN: EPSG:326NN в северном полушарии,
  EPSG:327NN в южном. Зона берётся по центру видимой части карты.
- Учитываются особые зоны у Норвегии (32V) и Шпицбергена (31X, 33X, 35X, 37X).
- Карта остаётся на том же месте, слои и их данные не меняются.
- Если центр карты севернее 84° или южнее 80° ю. ш., UTM там не определена:
  СК не меняется, в строке сообщений — предупреждение.

Требуется QGIS 3.40 или новее, рассчитан и на QGIS 4.

## Разработка

- `tests/run_tests.sh` — проверки на Python из QGIS без окна.
- `./build_zip.sh` — архив `dist/project_utm_crs-<версия>.zip`.
